========================================================================
                      WHATSAPP CHATBOT ARCHITECTURE
========================================================================

This document explains the high-level architecture of the WhatsApp Chatbot
Spring Boot application and provides details about the test suite.

------------------------------------------------------------------------
1. HIGH-LEVEL ARCHITECTURE OVERVIEW
------------------------------------------------------------------------

The application is a webhook receiver and message sender for Meta's WhatsApp 
Business Cloud API. It consists of the following components:

- Entrypoint: WhatsAppBotApplication.java
  The main Spring Boot startup class.

- Controller: WhatsAppWebhookController.java
  Exposes REST API endpoints:
  - GET /webhook: Subscription verification (verifies hub.verify_token and returns hub.challenge).
  - POST /webhook: Event notification (receives incoming payloads and delegates to service).

- Service: WhatsAppWebhookService.java
  Implements core message processing & sending:
  - Parses incoming JSON event payloads (entry -> changes -> value -> messages).
  - Sends text responses using Spring RestTemplate to Meta's Graph API (v25.0).

- Configuration: application.properties & .env
  Maps Meta credentials for verification and messaging:
  - WHATSAPP_ACCESS_TOKEN
  - WHATSAPP_PHONE_NUMBER_ID
  - WHATSAPP_VERIFY_TOKEN

- Deployment: Dockerfile
  Multi-stage build compiling Java 17 fat JAR and deploying to lightweight JRE image.

------------------------------------------------------------------------
2. TEST SUITE EXPLANATION (WhatsAppWebhookControllerTest.java)
------------------------------------------------------------------------

The test suite validates the REST endpoints of the webhook controller using MockMvc:
- GET /webhook (success and forbidden verification handling)
- POST /webhook (event receipt)
